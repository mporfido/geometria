📐 Proprietà dei Logaritmi

Proprietà 1: Logaritmo di un Prodotto

$\log_a(b \cdot c) = \log_a(b) + \log_a(c)$

Il logaritmo di un prodotto è uguale alla somma dei logaritmi

Esempio:

$\log_2(8 \cdot 4) = \log_2(8) + \log_2(4)$

$\log_2(32) = 3 + 2 = 5$

Verifica: $2^5 = 32$ ✓

Proprietà 2: Logaritmo di un Quoziente

$\log_a\left(\frac{b}{c}\right) = \log_a(b) - \log_a(c)$

Il logaritmo di un quoziente è uguale alla differenza dei logaritmi

Esempio:

$\log_2\left(\frac{16}{4}\right) = \log_2(16) - \log_2(4)$

$\log_2(4) = 4 - 2 = 2$

Verifica: $2^2 = 4$ ✓

Proprietà 3: Logaritmo di una Potenza

$\log_a(b^n) = n \cdot \log_a(b)$

Il logaritmo di una potenza è uguale all'esponente per il logaritmo della base

Esempio:

$\log_2(8^2) = 2 \cdot \log_2(8)$

$\log_2(64) = 2 \cdot 3 = 6$

Verifica: $2^6 = 64$ ✓
